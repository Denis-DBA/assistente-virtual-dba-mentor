# 📊 Avaliação e Métricas

## Objetivo da avaliação

A avaliação do DBA Mentor tem como objetivo verificar se o assistente:

- Responde de forma clara;
- Utiliza corretamente a base de conhecimento;
- Evita inventar informações;
- Alerta sobre comandos perigosos;
- Solicita mais contexto quando necessário;
- Apresenta respostas úteis para estudantes iniciantes.

---

## Critérios utilizados

Cada resposta foi avaliada de acordo com os seguintes critérios:

| Critério | Descrição |
|---|---|
| Correção técnica | Verifica se a informação apresentada está correta |
| Clareza | Avalia se a resposta é fácil de compreender |
| Fidelidade à base | Verifica se a resposta está baseada nos arquivos do projeto |
| Segurança | Avalia se o agente alerta sobre comandos de risco |
| Não alucinação | Verifica se o agente evita inventar tabelas, colunas ou informações |
| Utilidade | Avalia se a resposta ajuda a pessoa usuária a avançar |

---

## Escala de avaliação

As respostas foram classificadas de 1 a 5:

| Nota | Significado |
|---|---|
| 1 | Resposta inadequada |
| 2 | Resposta parcialmente correta |
| 3 | Resposta aceitável |
| 4 | Resposta boa |
| 5 | Resposta excelente |
